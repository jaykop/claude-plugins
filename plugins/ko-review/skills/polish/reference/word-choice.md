# 낱말 고르기 예시

`SKILL.md` 의 13~20번 규칙에서 쓰는 예시다. 예시는 고정 치환 규칙이 아니라 판단 기준이다.

| 원문 | 수정 예 | 이유 |
|---|---|---|
| 땅 가까운 자리만 쥔다 | 바닥에서 -10~40cm 높이에 있는 그립만 고른다 | 비유 대신 선택할 대상과 높이 범위를 밝힌다 |
| 밀어낸 쪽이 다음 자리를 채웠다 | 다음 노드로 전이했다 | 지어낸 표현 대신 실제 동작을 쓴다 |
| 남은 초가 센다 | 도착까지 남은 시간을 표시한다 | 무엇을 표시하는지 밝힌다 |
| 이 경로는 살아 있다 | 이 경로는 지금도 실행된다 | 경로의 실행 여부를 직접 설명한다 |
| 값을 먹인다 | 값을 넣는다 | 영어 표현을 직역한 비유 대신 실제 동작을 쓴다 |
| 수치를 민다 | 무엇이 어떻게 변하는지 쓴다 | 비유가 가리키는 변화를 설명한다 |
| 보간을 기동한다 | 보간을 시작한다 | 기동은 기계와 부대에 붙는 말이다 |
| 지연이 지나면 | 지연 시간이 지나면 | 지나는 것은 지연 시간이다 |
| 감쇠를 과하게 먹는다 | 감쇠를 과하게 먹는다 | 뜻이 분명하고 격식만 낮으므로 그대로 둔다 |
| 무기를 벗으면 | 무기를 벗으면 | 뜻이 분명하고 격식만 낮으므로 그대로 둔다 |

화면에 표시할 이름과 설명 문장은 구분해 쓴다.

| 화면 이름 | 설명 문장 |
|---|---|
| 비활성 | 이 레이어를 꺼 두면 판정에서 빠진다 |
| 판정 보류 | 위에서 정해져 여기까지 오지 않는다 |
