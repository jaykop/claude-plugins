# 리포트 본문 양식

공용 양식 `shared/report-base.md` 의 "본문" 자리에 넣는다. 머리 표, 요약, 결정이 필요한 것, 지난 리포트와 달라진 것, 확인 못 한 것, 다른 고문에게 넘긴 질문, 다음 점검 조건은 공용 양식이 맡는다. 여기서는 되풀이하지 않는다.

- 리포트 제목의 고문 이름은 "시장 동향 고문", 모드는 "전면 평가" 또는 "변화 점검"이다.
- 머리 표의 "범위"에는 본 지역, 본 묶음, 좁힌 대상(변화 점검), 에이전트 없이 수집했는지를 적는다.
- 본문에서 "올해", "요즘", "최근 몇 달" 같은 말 대신 연월(YYYY-MM)을 쓴다.
- 출처 번호는 본문 끝 "출처" 표의 번호다. 수치마다 붙인다.

## 변화 점검 본문

```markdown
### 조사 조건
| 항목 | 값 |
|---|---|
| 기준 전면 평가 | 경로 (조사 조건과 프로필 기준을 가져온 리포트) |
| 비교 기준 | market-snapshot.md 의 직전 조회일 |
| 좁힌 범위 | 전체 / <게임 ID·지역·지표> (요청 문장 또는 질문함 ID) |
| 프로필 기준 | 이번 실행의 값. 전면 평가 본문과 같은 칸 (기록용. 모드 판별은 기준 전면 평가의 같은 줄과 비교한다) |
| 프로필 기준 변화 | 기준 전면 평가와 비교해 없음 / <바뀐 칸> — 전면 평가 필요 |
| 표본 규칙·분류 체계 | 직전과 같음 / 바뀜(직접 비교 안 함) |

### 1. 지표 변화
(market_calc.py snapshot --new 출력 표에 아래 두 칸을 더한다. 직전 기록이 없던 지표는 직전 값 "없음", 차이 "첫 기록")
| 지표 ID | 게임 | 지표 | 직전 값 (조회일) | 이번 값 | 차이 | 증감률 | 변화로 인정 (잡음 규칙) | 출처 같음 |
|---|---|---|---|---|---|---|---|---|

### 2. 새로 생긴 것
| 종류 (신작·발표작 / 새 판 자료 / 실적 발표 / 지역 조건 변화 / 방법 변경) | 내용 | 선정 규칙 통과 (신작일 때) | 출처 번호 |
|---|---|---|---|

### 3. 축 등급 변화 (근거가 바뀐 축만. 없으면 "변화 없음")

|---|---|---|---|

### 4. 출시 조건 관련 새 관찰 (있을 때만, 전면 평가 8번 항목 양식)

### 5. 출처
### 6. 검색·계산 기록
```
